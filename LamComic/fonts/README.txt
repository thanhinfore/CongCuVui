HƯỚNG DẪN THÊM FONT iCiel Wild Words
=====================================

Để sử dụng font iCiel Wild Words Việt Hóa, bạn cần tải font và đặt vào thư mục này.

CÁC FILE CẦN CÓ:
- iCielWildWords.ttf (hoặc .woff / .woff2)
- iCielWildWords-Bold.ttf (hoặc .woff / .woff2) - tùy chọn

CÁCH LẤY FONT:
1. Tìm kiếm "iCiel Wild Words Việt Hóa" trên Google
2. Tải về từ các nguồn font Việt hóa như:
   - font.vn
   - fontchudep.vn
   - befonts.com
3. Giải nén và copy file .ttf/.woff vào thư mục này

LƯU Ý:
- Font iCiel Wild Words là font thương mại, hãy đảm bảo bạn có quyền sử dụng
- Nếu không có font này, hệ thống sẽ tự động dùng font fallback (Baloo 2)

ĐỔI TÊN FILE (nếu cần):
- iCielWildWords.ttf
- iCielWildWords.woff
- iCielWildWords.woff2
- iCielWildWords-Bold.ttf
- iCielWildWords-Bold.woff
- iCielWildWords-Bold.woff2
